Настройки строгости коуча

Что проверяет коуч на каждом шаге?

1

Базовая проверка

Код существует + импортируется без ошибок. Быстро, мало API вызовов.

2

Запуск + визуальная проверка

Запускает код, проверяет что конкретное требование видно/работает. Рекомендуется.

3

Тесты на каждый шаг

Коуч пишет тест под каждый пункт плана и прогоняет его. Медленно но надёжно.
