# Graph-Aware Contract Analysis Debugger

## Context

Replace chunk-based debugger with graph-aware system. Current approach analyzes files in isolated 200K-char chunks — cross-file bugs (contract violations, signature mismatches, return value mishandling) are invisible. New system: AST dependency graph → LLM contracts per file → edge analysis → deep dive → intra-file with contracts → test & fix.

## Steps

- [ ] Create `src/debugger_graph.py` — static dependency graph module. Implement dataclasses: `FunctionSig`, `ClassSig`, `ImportEdge`, `ExternalCall`, `FileNode`, `DependencyGraph`. Implement functions: `discover_py_files()` (move from `debugger_context.py` with `_SKIP_DIRS`), `parse_file()` (uses `ast.parse` to extract signatures, imports, external calls), `resolve_import()` (maps module path to file, None for stdlib/external), `build_dependency_graph()` (discovers files, parses all, builds edges, computes SCCs), `find_sccs()` (Tarjan's algorithm). Handle relative imports (`from . import X`) and absolute project imports (`from src.X import Y`). Skip stdlib/third-party gracefully. Pure stdlib: `ast`, `pathlib`, `dataclasses`.

- [ ] Create `src/debugger_contracts.py` — contract extraction module. Implement dataclasses: `ExportContract` (name, signature, preconditions, postconditions, side_effects, raises, return_type), `ImportUsage` (source_module, symbol, usage_description), `FileContract` (rel_path, exports, imports_usage, invariants, source_hash). Implement functions: `build_contract_prompt()` (file source + AST metadata → prompt for JSON contract), `parse_contract_response()` (reuse `_extract_json_from_text` from `debugger_bugs.py`), `extract_contracts()` (async orchestrator, batches small files 5-10 per LLM call via `batch_files()`), `load_cached_contracts()` / `save_cached_contracts()` (cache in `.g3/contracts_cache.json` keyed by sha256 hash), `is_contract_stale()` (compare hash). Depends on `debugger_graph.py` for `FileNode`.

- [ ] Create `src/debugger_edges.py` — cross-file edge analysis + deep dive module. Implement dataclass: `EdgeFinding` (caller_file, callee_file, caller_line, description, confidence: high/medium/low, check_type: signature_mismatch/return_ignored/none_not_handled/exception_uncaught/side_effect_order/type_mismatch). Implement functions: `build_edge_prompt()` (caller FULL source + dependency CONTRACTS), `build_scc_prompt()` (all SCC files full source for circular deps), `parse_edge_findings()`, `analyze_edges()` (one LLM call per file with all outgoing edges — O(N) not O(E)), `deep_dive()` (medium confidence → load full source of both files, confirm/refute), `findings_to_bugs()` (convert high-confidence EdgeFindings to BugEntry). Depends on `debugger_graph.py` and `debugger_contracts.py`.

- [ ] Create `src/debugger_intra.py` — per-file intra-file analysis with contract context. Implement functions: `build_intra_prompt()` (file FULL source + CONTRACTS of all its dependencies — ~11K context instead of 200K chunk), `analyze_file()` (runs all intensity passes MAIN/ANCHOR/RED_TEAM/BOUNDARY/COMPLETENESS on one file with contracts), `analyze_all_files()` (iterates all files, no chunking). Reuse `parse_bugs` from `debugger_bugs.py` and `INTENSITY_PROMPTS` from `debugger_prompts.py`. Add note to prompts: "You are also given contracts for imported modules that describe their interfaces."

- [ ] Add new prompts to `src/debugger_prompts.py` — add `CONTRACT_EXTRACTION_PROMPT` (instructs LLM to output JSON contract with exports/imports_usage/invariants, include example, "maximum 100 words per function contract"), `EDGE_ANALYSIS_PROMPT` (check caller source against dependency contracts for 6 mismatch types, output JSON array with confidence levels), `SCC_ANALYSIS_PROMPT` (circular dependency variant emphasizing mutual state mutation and initialization ordering), `DEEP_DIVE_PROMPT` (confirm/refute suspected cross-file bug given full source of both files). Keep all existing prompts unchanged: `PLAYER_PROMPT_MAIN`, `PLAYER_PROMPT_ANCHOR`, `PLAYER_PROMPT_RED_TEAM`, `PLAYER_PROMPT_BOUNDARY`, `PLAYER_PROMPT_COMPLETENESS`, `TESTER_PROMPT`, `FIXER_PROMPT`.

- [ ] Add config fields to `src/config.py` — add after line 138: `debug_cache_contracts: bool = True`, `debug_deep_dive_threshold: str = "medium"` (high=skip dive, medium=default, low=dive everything), `debug_edge_batch_size: int = 5`, `debug_max_concurrent_llm: int = 5`. Add corresponding entries to `_ENV_MAP`: `G3_DEBUG_CACHE_CONTRACTS`, `G3_DEBUG_DEEP_DIVE_THRESHOLD`, `G3_DEBUG_EDGE_BATCH_SIZE`, `G3_DEBUG_MAX_CONCURRENT_LLM`. Reuse existing `debug_victory_threshold` for intra-file clean pass count.

- [ ] Rewrite `src/debugger.py` — replace chunk-based loop with phased pipeline. KEEP: `_Pulse` class, `DebuggerResult`, `_CollectedTextResult`, `_collect_text()`, `_extract_text()`, `_should_stop()`, `_git_commit()`, `_parse_tester_results()`, `_verify_confirmed_fixes()`, `_mark_inconclusive()`, color helpers, `_compact_status()`, `_display_final()`. REMOVE: `self._chunks`, `self._chunk_cursor`, `_next_chunk()`, `_display_iteration_header()`, `_run_player()`, import of `build_context`/`plan_file_chunks`. ADD: new `__init__` with `self._graph` and `self._contracts`. New `run()` flow: Phase 0 (`build_dependency_graph`) → Phase 1 (`extract_contracts` with caching) → Phase 2 (`analyze_edges`, high→BugEntry, medium→deep dive queue) → Phase 3 (`deep_dive` on medium findings) → Phase 4 (intra-file loop: `analyze_all_files` until clean passes >= threshold) → Phase 5 (test & fix: `_run_tester` → `_run_fixer` → `_verify_confirmed_fixes` → `_git_commit`). MODIFY `_run_tester` and `_run_fixer`: replace `build_context` with new `build_context_from_graph(graph, file_subset, contracts)` that renders files with line numbers + dependency contracts in same markdown format. Add `_display_phase_header()` for phase banners.

- [ ] Delete `src/debugger_context.py` — verify no other module imports from it (grep for `from src.debugger_context` and `import debugger_context`). Remove or update any tests that reference chunk-based functionality.

- [ ] Write tests for `debugger_graph.py` — test `parse_file` with synthetic .py strings producing expected FunctionSig/ImportEdge/ExternalCall. Test `find_sccs` with known cyclic graph (A→B→C→A). Test `build_dependency_graph` with tmp_path containing 3-4 small .py files importing each other. Test `resolve_import` handles relative, absolute, and external imports.

- [ ] Write tests for `debugger_contracts.py` — mock LLM provider to return known JSON contract strings. Test `parse_contract_response` with well-formed and malformed inputs. Test caching: write cache, modify one file source, verify only stale file is re-extracted. Test `batch_files`: 10 small files → 2 batches, 1 large file → own batch.

- [ ] Write tests for `debugger_edges.py` — mock LLM to return known edge findings with various confidence levels. Test `findings_to_bugs` conversion (high→BugEntry). Test SCC grouping (files in same SCC get one call). Test deep dive: medium finding → LLM confirms → high; LLM refutes → dismissed.

- [ ] Write tests for `debugger_intra.py` — mock LLM, verify constructed user prompt contains file source AND dependency contracts. Verify `parse_bugs` called correctly. Test that bugs from all files merge correctly.

- [ ] Verify integration — run new debugger on tero itself (`tero go debug`). Verify it produces a graph, extracts contracts, runs edge analysis, runs intra-file analysis. Check that `DebuggerResult` format is unchanged. Check that `bugs.md`/`bugs_final.md` format is unchanged. Check git commit messages follow `fix(debugger): iteration N — M bug(s) fixed` pattern.
