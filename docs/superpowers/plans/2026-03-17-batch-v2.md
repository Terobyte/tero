# Batch Orchestration v2 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make batch judge/pre/post slots fully configurable (any provider + model per slot), and turn the single-pass code review into an iterative loop (reviewer → player fix → reviewer) until zero bugs found.

**Architecture:** New Config fields drive `_review_strategy()` in `batch_executor.py`, replacing hardcoded `JUDGE_PROVIDER`/`JUDGE_MODEL` class constants. The iterative code review loop replaces the single-pass block in `CoachPlayerSession.run()`: after Coach approval, the reviewer runs, if bugs found the player fixes via `_run_with_continuation()`, then the reviewer runs again — up to `max_review_iterations`. All iterations logged to `<working_dir>/.g3/bugs/`.

**Tech Stack:** Python dataclasses, pytest, questionary (menu TUI)

**Depends on:** Plan A Tasks 2 + 5 (`context_manager._log_review_result` and `CoachPlayerSession._run_with_continuation`). Task B7 below notes the fallback if Plan A is incomplete.

**Spec:** `docs/superpowers/specs/2026-03-17-context-management-batch-v2-design.md` — Part 2

def _review_strategy(self, attempt_num: int) -> dict[str, str]:
    """Return review strategy for a 1-based batch attempt number."""
    pre_attempts, judge_attempts, _post_attempts = self._schedule_counts()
    judge_start = pre_attempts + 1
    judge_end = pre_attempts + judge_attempts

    if judge_attempts > 0 and judge_start <= attempt_num <= judge_end:
        return {
            "header_role": "judge",
            "label": self._judge_label(),
            "provider_name_override": self.session.config.batch_judge_provider,
            "model_override": self.session.config.batch_judge_model,
            "review_role": "judge",
        }

    return {
        "header_role": "coach",
        "label": self._role_label("coach"),
        "provider_name_override": self.session.config.batch_pre_provider,
        "model_override": self.session.config.batch_pre_model,
        "review_role": "coach",
    }
