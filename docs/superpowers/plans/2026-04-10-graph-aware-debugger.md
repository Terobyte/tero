## Phase 1: Dependency Graph Module

- [ ] Create `src/debugger_graph.py` — implement all 6 dataclasses: `FunctionSig` (name, args, returns, lineno, is_async), `ClassSig` (name, methods, bases, lineno), `ImportEdge` (source_file, target_module, symbols, lineno, resolved_path), `ExternalCall` (caller_func, callee_module, callee_name, lineno), `FileNode` (rel_path, functions, classes, imports, external_calls, line_count, source_hash), `DependencyGraph` (files, edges, sccs, with `dependents_of()` and `dependencies_of()` helper methods)
- [ ] Implement `discover_py_files(working_dir)` — move from `debugger_context.py`, keep same `_SKIP_DIRS` set (`.git/venv/.venv/node_modules/__pycache__/.mypy_cache/.pytest_cache/.tox/.eggs/dist/build/.ruff_cache/.hypothesis/tests/test/docs/.worktrees`). Return sorted list of relative paths.
- [ ] Implement `parse_file(path, rel_path, working_dir) -> FileNode | None` — uses `ast.parse` to extract: function signatures (name, args, returns, lineno, is_async from `ast.FunctionDef`/`ast.AsyncFunctionDef`), class signatures (name, methods as `FunctionSig` list, bases, lineno from `ast.ClassDef`), import edges (from `ast.Import`/`ast.ImportFrom`, call `resolve_import` for each, store `resolved_path`), external calls via import_map + first-level alias tracking. Build `import_map: dict[str, str]` from imports (e.g. `{"Config": "src.config"}`). Track first-level aliases: scan `ast.Assign` at module level and inside `__init__` — if `value` is `ast.Name(id=X)` where X in import_map, add alias. Find `ast.Call` where `func` is `ast.Attribute(value=ast.Name(id=X))` and X in import_map → `ExternalCall`. Compute sha256 of file content. Return `None` on `SyntaxError`.
- [ ] Implement `resolve_import(module_path, working_dir, source_file=None, level=0) -> str | None` — for relative imports (level > 0): compute base_dir from source_file dirname, go up (level-1) directories, join module_path as subpath, try `.py` then `/__init__.py`. For absolute imports (level=0): check `sys.stdlib_module_names` (Python 3.10+) → None if stdlib, try `working_dir/path.py` then `working_dir/path/__init__.py` → None if not found (third-party). Handle: `from src.X import Y` → `src/X.py`, `from . import X` → relative, `from .. import X` → up 1 level, `from .sub.mod import X` → `source_dir/sub/mod.py`, `import json` → None, `import requests` → None, `import src.providers` → `src/providers/__init__.py`. If level > 0 and source_file is None → return None.
- [ ] Implement `build_dependency_graph(working_dir) -> DependencyGraph` — discover files → parse all → collect resolved ImportEdges → build adjacency dict → `find_sccs()` → filter to SCCs with 2+ nodes → return DependencyGraph
- [ ] Implement `find_sccs(adjacency: dict[str, list[str]]) -> list[list[str]]` — Tarjan's algorithm, single DFS pass, O(V+E). Returns all SCCs including single-node; caller filters to 2+ nodes.
- [ ] Write `tests/test_debugger_graph.py` — 17 tests: `test_parse_file_functions` (3 functions → FunctionSig), `test_parse_file_classes` (class + methods → ClassSig), `test_parse_file_imports` (from/import → ImportEdge with resolved_path), `test_parse_file_external_calls` (Y.method() → ExternalCall), `test_parse_file_alias_tracking` (provider = create_provider(); provider.run() → alias resolved), `test_parse_file_syntax_error` (malformed .py → None), `test_resolve_import_absolute` (tmp_path), `test_resolve_import_relative_dot` (level=1), `test_resolve_import_relative_dotdot` (level=2), `test_resolve_import_stdlib` (json → None), `test_resolve_import_third_party` (requests → None), `test_resolve_import_package_init` (__init__.py), `test_find_sccs_cycle` (A→B→C→A), `test_find_sccs_no_cycle` (A→B→C → empty), `test_find_sccs_two_cycles` (A↔B, C↔D), `test_build_dependency_graph` (tmp_path with 4 files), `test_dependency_graph_helpers` (dependents_of, dependencies_of)
- [ ] Run `python -m pytest tests/test_debugger_graph.py -x -q --tb=short` — all tests pass

## Phase 2: Contract Extraction Module

- [ ] Create `src/debugger_contracts.py` — implement 3 dataclasses: `ExportContract` (name, signature, preconditions, postconditions, side_effects, raises, return_type), `ImportUsage` (source_module, symbol, usage_description), `FileContract` (rel_path, exports, imports_usage, invariants, source_hash)
- [ ] Implement `build_contract_prompt(source, file_node) -> str` — file source with line numbers + AST summary (function signatures, class names, import list from FileNode) → prompt for LLM. Constraint text: "Maximum 100 words per function contract"
- [ ] Implement `build_batch_prompt(files: list[tuple[str, str, FileNode]]) -> str` — multiple files in one prompt separated by `--- File: {rel_path} ---`. LLM returns JSON keyed by rel_path.
- [ ] Implement `parse_contract_response(raw) -> dict[str, FileContract] | FileContract` — reuse `extract_json_from_text` from `debugger_bugs.py`. Dict with keys=rel_paths → batch response. Dict with key "exports" → single file. Missing fields → empty lists. Malformed JSON → retry strategies. Unparseable → empty contract (no crash). Serialize/deserialize nested dataclasses via `dataclasses.asdict()` and manual construction from dicts.
- [ ] Implement `batch_files(file_nodes, working_dir) -> list[list[str]]` — read source for each file, sort by size ascending, greedy bin-pack into batches up to `PROMPT_BUDGET = 15_000` chars. Small files (conftest.py, __init__.py) grouped. Large files get own batch.
- [ ] Implement `extract_contracts(graph, provider, config, working_dir) -> dict[str, FileContract]` — async orchestrator: load cache → identify stale files (hash mismatch) → batch stale files → process batches with `asyncio.Semaphore(config.debug_max_concurrent_llm)` via `asyncio.gather(*tasks, return_exceptions=True)` → update cache → save → return full dict. Uses `collect_text` from `debugger_llm.py`.
- [ ] Implement `load_cached_contracts(cache_path) -> dict[str, FileContract]` — reads `.g3/contracts_cache.json`. Missing or invalid JSON → empty dict.
- [ ] Implement `save_cached_contracts(contracts, cache_path)` — atomic write: write to `{cache_path}.tmp` → `os.replace()` to final path.
- [ ] Implement `is_contract_stale(contract, current_hash) -> bool` — `contract.source_hash != current_hash`
- [ ] Write `tests/test_debugger_contracts.py` — 13 tests: `test_parse_contract_response_valid`, `test_parse_contract_response_missing_fields` (no "raises" → raises=[]), `test_parse_contract_response_malformed` (broken JSON → empty contract), `test_parse_contract_response_batch` (multi-file JSON), `test_batch_files_small` (10×500 chars → 1 batch), `test_batch_files_mixed` (8 small + 2 large), `test_batch_files_single_large` (1×20K → own batch), `test_cache_fresh` (hash match → skip), `test_cache_stale` (change 1 file → only that re-extracted), `test_cache_missing` (no file → extract all), `test_cache_atomic_write` (verify tmp + rename), `test_extract_contracts_concurrency` (10 files, sem=2), `test_extract_contracts_error_handling` (1 batch fails → others succeed)
- [ ] Run `python -m pytest tests/test_debugger_contracts.py -x -q --tb=short` — all tests pass

## Phase 3: New Prompts

- [ ] Add `CONTRACT_EXTRACTION_PROMPT` to `src/debugger_prompts.py` — instructs LLM to output JSON contract with exports (name, signature, preconditions, postconditions, side_effects, raises, return_type), imports_usage, invariants. Include example JSON in the prompt. Enforce "maximum 100 words per function contract". Document batch format (JSON keyed by rel_path when multiple files). Include public-only rule (skip private `_` helpers).
- [ ] Add `EDGE_ANALYSIS_PROMPT` to `src/debugger_prompts.py` — instructs LLM to check caller source against dependency contracts for 6 mismatch types: `signature_mismatch`, `return_ignored`, `none_not_handled`, `exception_uncaught`, `side_effect_order`, `type_mismatch`. Output JSON array of `{caller_file, callee_file, caller_line, description, confidence: high|medium|low, check_type}`. Include descriptions and examples of each check type. Explicitly state: do NOT report intra-file bugs, do NOT report style issues.
- [ ] Add `SCC_ANALYSIS_PROMPT` to `src/debugger_prompts.py` — circular dependency variant. Focus on: initialization ordering (import-time AttributeError), mutual state mutation (stale state), contract violations across all directions in cycle, re-import side effects. Same output format as EDGE_ANALYSIS_PROMPT.
- [ ] Add `DEEP_DIVE_PROMPT` to `src/debugger_prompts.py` — template string with `{caller_file}`, `{callee_file}`, `{caller_line}`, `{check_type}`, `{description}` placeholders. LLM gets full source of both files. Output: `{"confirmed": bool, "reason": str}`. Use double braces `{{` `}}` for JSON examples inside f-string template.
- [ ] Add `CONTRACT_AWARENESS_PREFIX` to `src/debugger_prompts.py` — one-liner prepended to existing INTENSITY_PROMPTS at call time: `"You are also given contracts for imported modules that describe their interfaces. Use these contracts to verify cross-module interactions within this file.\n\n"`. NOT a modification of existing prompts — a separate constant.
- [ ] Keep ALL existing prompts unchanged: `PLAYER_PROMPT_MAIN`, `PLAYER_PROMPT_ANCHOR`, `PLAYER_PROMPT_RED_TEAM`, `PLAYER_PROMPT_BOUNDARY`, `PLAYER_PROMPT_COMPLETENESS`, `TESTER_PROMPT`, `FIXER_PROMPT`, `INTENSITY_PROMPTS`

## Phase 4: Edge Analysis Module

- [ ] Create `src/debugger_edges.py` — implement `EdgeFinding` dataclass: caller_file, callee_file, caller_line, description, confidence (high|medium|low), check_type (one of 6 types: signature_mismatch, return_ignored, none_not_handled, exception_uncaught, side_effect_order, type_mismatch)
- [ ] Implement `build_edge_prompt(caller_source, caller_node, dep_contracts) -> str` — caller FULL source with line numbers + "## Dependency Contracts" section listing each dep's ExportContracts (name, signature, pre/post/side_effects/raises/return_type). Format each contract as compact bullet list.
- [ ] Implement `build_scc_prompt(scc_files: list[tuple[str, str]]) -> str` — all SCC files full source with line numbers, each under `### File: {rel_path}`. Header: "## Circular Dependency Group — These files have circular imports."
- [ ] Implement `parse_edge_findings(raw) -> list[EdgeFinding]` — reuse `extract_json_from_text` from `debugger_bugs.py`. Validate: confidence must be in {"high", "medium", "low"} (invalid → "low"), check_type must be one of 6 types (invalid → "type_mismatch"), caller_line must be int > 0 (invalid → 0). Skip entries with missing required fields (caller_file, callee_file, description).
- [ ] Implement `analyze_edges(graph, contracts, provider, config, working_dir) -> tuple[list[EdgeFinding], list[EdgeFinding]]` — returns (high_findings, medium_findings), low discarded. Algorithm: (1) identify scc_files set, (2) process each SCC group: one LLM call per SCC with SCC_ANALYSIS_PROMPT + build_scc_prompt, (3) process non-SCC files: one LLM call per file with EDGE_ANALYSIS_PROMPT + build_edge_prompt — skip files with no project deps or no dep contracts, (4) all calls via `asyncio.Semaphore(config.debug_max_concurrent_llm)` and `asyncio.gather`, (5) split results by confidence. Uses `collect_text` from `debugger_llm.py`.
- [ ] Implement `deep_dive(finding, working_dir, provider, config) -> EdgeFinding | None` — read caller_source and callee_source, format DEEP_DIVE_PROMPT with finding details + both full sources, call LLM, parse `{"confirmed": bool, "reason": str}`. If confirmed: set confidence="high", append reason to description, return finding. If refuted: return None.
- [ ] Implement `run_deep_dives(medium_findings, working_dir, provider, config) -> list[EdgeFinding]` — orchestrate dives based on `config.debug_deep_dive_mode`: "skip" → return [], "normal" → dive top 10 medium findings (sorted by caller_line for determinism), "aggressive" → dive ALL medium findings. Uses `asyncio.Semaphore`. Returns list of confirmed findings.
- [ ] Implement `findings_to_bugs(findings, start_id=1) -> list[BugEntry]` — convert EdgeFinding → BugEntry: `file=caller_file, line=caller_line, description=f"[{check_type}] {description}", severity="high", status="open"`
- [ ] Write `tests/test_debugger_edges.py` — 13 tests: `test_parse_edge_findings_valid`, `test_parse_edge_findings_invalid_confidence` ("very_high" → "low"), `test_parse_edge_findings_missing_fields` (no caller_line → skipped), `test_build_edge_prompt_structure` (contains source + "Dependency Contracts"), `test_build_scc_prompt_structure` (all SCC files present), `test_analyze_edges_skips_no_deps` (no project deps → no LLM call), `test_analyze_edges_scc_grouping` (A↔B → one SCC call), `test_analyze_edges_confidence_split` (mixed → correct split), `test_deep_dive_confirmed` (mock confirms → high confidence), `test_deep_dive_refuted` (mock refutes → None), `test_run_deep_dives_skip_mode` (returns []), `test_run_deep_dives_concurrency` (5 findings, sem=2), `test_findings_to_bugs` (3 findings → 3 BugEntry with [check_type] prefix)
- [ ] Run `python -m pytest tests/test_debugger_edges.py -x -q --tb=short` — all tests pass

## Phase 5: Intra-File Analysis Module

- [ ] Create `src/debugger_intra.py` — implement `build_intra_prompt(file_source, file_node, dep_contracts) -> str`: file source with line numbers + "## Dependency Contracts" section (same format as edge prompt). If no project deps → no contracts section.
- [ ] Implement `analyze_file(rel_path, file_source, file_node, contracts, graph, provider, config) -> list[BugEntry]` — get deps via `graph.dependencies_of(rel_path)`, get dep_contracts, build user_prompt via `build_intra_prompt`, get system prompts from `INTENSITY_PROMPTS[config.debug_intensity]`.
