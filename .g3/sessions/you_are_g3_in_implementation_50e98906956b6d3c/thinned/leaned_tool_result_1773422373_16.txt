## 1. Обзор архитектуры

### Проблема

Текущий бот умеет подавать на **известные ATS** (Greenhouse, Lever, Workday, Ashby, BambooHR, SmartRecruiters, Indeed, LinkedIn).
Но **~30-40% вакансий** ведут на **кастомные карьерные сайты** компаний, у которых:

- Уникальная DOM-структура (нет `data-automation-id`, нет стандартных CSS классов)
- Нестандартный wizard flow (2-10 шагов, иногда single-page)
- Custom dropdowns, comboboxes, date pickers
- OAuth / SSO / account creation barriers
- Нестандартные файл-аплоадеры

### Решение: "Blind Navigator" — AI-First Approach


### AI Model Roles

| Model | Role | Зачем именно эта модель |
|-------|------|------------------------|
| **Kimi 2.5** (`blackboxai/moonshotai/kimi-k2.5`) | Vision analysis: скриншот → понять что на экране | Мультимодальная, понимает изображения, быстрая, дешёвая |
| **Gemini 3 Flash** (`gemini-3-flash-preview`) | Semantic DOM analysis + selector generation | Быстрая, дешёвая, отличный structured output (JSON) |

| **GLM-5** (`z-ai/glm-5`) | Fallback / debugging agent | Огромный контекст (200K), хорош для анализа HTML |

## 2. Phase 0 — Site Reconnaissance

> **Файл**: `src/applier/blind/recon_agent.py`
> **Цель**: Понять структуру сайта ДО того как начнём заполнять

### 2.1 Что делает Recon Agent

1. **Загружает страницу** через `StealthBrowser`
2. **Делает скриншот** (PNG, full page)
3. **Извлекает DOM-snapshot** (минимальный — только видимые элементы)
4. **Отправляет в Kimi 2.5** (vision) для понимания:
   - Тип страницы: `job_listing` | `login_required` | `application_form` | `multi_step_wizard` | `confirmation`
   - Есть ли кнопка "Apply" и где она
   - Есть ли требование аккаунта / SSO
   - Язык интерфейса
5. **Строит SiteSchema** — JSON-описание сайта

### 2.2 SiteSchema Format

```python
@dataclass
class SiteSchema:
    """Результат разведки кастомного сайта."""
    url: str
    domain: str
    page_type: str           # job_listing | login_required | form_single | form_wizard | confirmation | error
    requires_account: bool   # Нужна ли регистрация/логин
    has_apply_button: bool   # Есть ли кнопка Apply на текущей странице
    apply_button_hint: str   # Описание кнопки для LLM (e.g., "blue button labeled 'Apply Now'")
    estimated_steps: int     # Оценка количества шагов (1 для single-page)
    language: str            # en, es, etc.
    detected_ats: str        # Если всё-таки похож на известный ATS → delegate
    form_fields_preview: list[dict]  # Список видимых полей [{label, type_guess}]
    blocked_reason: str | None  # Причина блока (captcha, geo-block, 404)
    screenshot_path: str     # Путь к скриншоту для кэширования
    raw_dom_hash: str        # Hash минимального DOM для кэширования
    confidence: float        # 0.0-1.0 уверенность AI в своём анализе
```

### 2.3 DOM Extraction (Lean)

```python
RECON_DOM_JS = """
() => {
    const result = { buttons: [], links: [], forms: [], inputs: [] };
    
    // Кнопки
    document.querySelectorAll('button, a[role="button"], input[type="submit"]').forEach(el => {
        const rect = el.getBoundingClientRect();
        if (rect.width === 0 || rect.height === 0) return;
        result.buttons.push({
            text: el.textContent?.trim().slice(0, 80),
            tag: el.tagName.toLowerCase(),
            href: el.href || null,
            type: el.type || null,
            bbox: { x: Math.round(rect.x), y: Math.round(rect.y), w: Math.round(rect.width), h: Math.round(rect.height) }
        });
    });
    
    // Forms
    document.querySelectorAll('form').forEach(form => {
        result.forms.push({
            action: form.action || null,
            method: form.method || 'get',
            fields_count: form.querySelectorAll('input, select, textarea').length
        });
    });
    
    // Inputs (только видимые)
    document.querySelectorAll('input:not([type="hidden"]), select, textarea').forEach(el => {
        const rect = el.getBoundingClientRect();
        if (rect.width === 0 || rect.height === 0) return;
        
        const label = document.querySelector(`label[for="${el.id}"]`)?.textContent?.trim()
                    || el.getAttribute('aria-label')
                    || el.placeholder
                    || el.name
                    || '';
        
        result.inputs.push({
            label: label.slice(0, 100),
            type: el.type || el.tagName.toLowerCase(),
            required: el.required || el.hasAttribute('required'),
            name: el.name || null,
            id: el.id || null
        });
    });
    
    // Login indicators
    result.has_login_form = result.inputs.some(i => 
        i.type === 'password' || (i.label && i.label.toLowerCase().includes('password'))
    );
    
    result.page_title = document.title;
    result.meta_description = document.querySelector('meta[name="description"]')?.content || '';
    
    return result;
}
"""
```

## 3. Phase 1 — Intelligent Page Navigator

> **Файл**: `src/applier/blind/page_navigator.py`  
> **Цель**: Навигация по сайту от landing page до формы заявки

### 3.1 Проблема

Когда URL ведёт на кастомный сайт, нужно:
1. Определить где мы (listing? login? form?)
2. Найти кнопку "Apply" и кликнуть
3. Если нужен логин — пропустить (или попробовать guest apply)
4. Если форма за iframe — найти iframe
5. Если форма за redirect — следить за URL

### 3.2 Navigation State Machine

```
[START] → [RECON] → page_type?
                     ├── job_listing     → [FIND_APPLY_BUTTON] → [CLICK] → [RECON again]
                     ├── login_required  → [TRY_GUEST] or [SKIP]
                     ├── form_single     → [FILL_FORM]
                     ├── form_wizard     → [WIZARD_ENGINE]
                     ├── confirmation    → [SUCCESS]
                     ├── error           → [MARK_FAILED]
                     └── unknown         → [VISION_ASSIST] → retry
```

### 3.4 Координатный клик (Kimi 2.5 + Playwright)

Когда Gemini не может найти CSS-selector (нестандартный UI), используем **Kimi 2.5 Vision**
для определения координат на скриншоте:

```python
async def vision_click(self, page, screenshot: bytes, target_description: str) -> bool:
    """
    Кликнуть по элементу используя Vision AI.
    
    1. Kimi 2.5 анализирует скриншот
    2. Возвращает bounding box {x, y, width, height}
    3. Playwright кликает по центру bbox
    """
    prompt = f"""Look at this screenshot. Find the element: {target_description}
    
    Return ONLY JSON with the bounding box coordinates:
    {{"x": 150, "y": 300, "width": 120, "height": 40}}
    
    If not found, return: {{"not_found": true}}
    """
    
    response = await self._kimi_vision.generate_with_image(prompt, screenshot)
    bbox = json.loads(response)
    
    if bbox.get("not_found"):
        return False
    
    # Click center of bounding box
    cx = bbox["x"] + bbox["width"] // 2
    cy = bbox["y"] + bbox["height"] // 2
    
    await page.mouse.click(cx, cy)
    return True
```

### 3.5 Kimi 2.5 Vision Client Extension

Расширяем `KimiClient` для поддержки изображений:

```python
class KimiVisionClient:
    """
    Kimi 2.5 with vision capabilities.
    Extends KimiClient to support image+text prompts.
    """
    
    BASE_URL = "https://api.blackbox.ai"
    MODEL = "blackboxai/moonshotai/kimi-k2.5"
    
    async def generate_with_image(self, prompt: str, image_bytes: bytes) -> str:
        """Send image + text prompt to Kimi 2.5 vision."""
        import base64
        
        image_b64 = base64.b64encode(image_bytes).decode()
        
        messages = [{
            "role": "user",
            "content": [
                {
                    "type": "image_url",
                    "image_url": {"url": f"data:image/png;base64,{image_b64}"}
                },
                {
                    "type": "text",
                    "text": prompt
                }
            ]
        }]
        
        client = AsyncOpenAI(api_key=self.api_key, base_url=self.BASE_URL)
        response = await client.chat.completions.create(
            model=self.MODEL,
            messages=messages,
            max_tokens=1024,
        )
        return response.choices[0].message.content or ""
```

### 4.3 Enhanced Field Finding

Для кастомных сайтов `universal_ai_filler.py` может не хватить, потому что:
- Custom React/Vue dropdowns (не `<select>`)
- Custom date pickers (не `<input type="date">`)
- Custom file uploaders (не `<input type="file">`)
- Shadow DOM

```python
class BlindFieldFinder:
    """
    Дополнительный слой поиска полей для кастомных сайтов.
    Использует визуальный анализ когда DOM-анализ не работает.
    """
    
    async def find_custom_dropdowns(self, page) -> list:
        """
        Найти кастомные dropdowns (React Select, MUI Select, etc.)
        
        Стратегии:
        1. [role="combobox"] / [role="listbox"]
        2. div[class*="select"] / div[class*="dropdown"]
        3. aria-expanded / aria-haspopup attributes
        4. Vision: "dropdown-like" элементы на скриншоте
        """
        
    async def find_custom_file_uploads(self, page) -> list:
        """
        Найти кастомные файл-аплоадеры.
        
        Стратегии:
        1. Standard <input type="file">
        2. Drag-and-drop zones (class*="dropzone", class*="upload")
        3. Buttons with upload text + hidden file input
        4. Vision: "upload area" на скриншоте
        """
        
    async def fill_custom_dropdown(self, page, element, value: str) -> bool:
        """
        Заполнить кастомный dropdown:
        1. Кликнуть по элементу (открыть)
        2. Подождать popup/listbox
        3. Найти опцию по тексту
        4. Кликнуть по опции
```

### 5.3 Loop-Protection

```python
class StepTracker:
    """
    Отслеживание шагов wizard'а.
    Защита от бесконечных циклов и застревания.
    """
    
    def __init__(self, max_steps: int = 15):
        self._steps: list[StepSnapshot] = []
        self.max_steps = max_steps
    
    def record_step(self, url: str, dom_hash: str, screenshot_hash: str):
        """Записать текущий шаг."""
        snap = StepSnapshot(url=url, dom_hash=dom_hash, screenshot_hash=screenshot_hash)
        
        # Проверка цикла: если такой же шаг уже был 2+ раз → stuck
        similar = [s for s in self._steps if s.dom_hash == dom_hash]
        if len(similar) >= 2:
            raise WizardStuckError(f"Stuck on same step (seen {len(similar)+1} times)")
        
        self._steps.append(snap)
        
        if len(self._steps) > self.max_steps:
            raise WizardMaxStepsError(f"Exceeded {self.max_steps} steps")
    
    def get_field_diff(self, prev_step: int) -> dict:
        """Что изменилось между шагами."""
```

### 7.3 Replay Recorder

```python
class ReplayRecorder:
    """
    Записывает последовательность действий для replay.
    
    Actions:
    - navigate(url)
    - click(selector | coordinates)
    - fill(selector, value)
    - select(selector, option)
    - upload(selector, file_path)
    - wait(condition | seconds)
    - screenshot(name)
    """
    
    def __init__(self, job_id: str, domain: str):
        self._actions: list[dict] = []
        self._job_id = job_id
        self._domain = domain
    
    def record(self, action_type: str, **kwargs):
        """Записать действие."""
        self._actions.append({
            "type": action_type,
            "timestamp": time.time(),
            **kwargs
        })
    
    def save(self, success: bool):
        """Сохранить replay файл."""
        path = Path(f"data/blind_site_workflows/{self._domain}_{self._job_id}.json")
        path.parent.mkdir(parents=True, exist_ok=True)
        data = {
            "domain": self._domain,
            "job_id": self._job_id,
            "success": success,
            "actions": self._actions,
            "recorded_at": datetime.now().isoformat(),
        }
        path.write_text(json.dumps(data, indent=2))
```

### 7.4 Learning Flow

```
First Visit to custom-company.com:
  1. ReconAgent → SiteSchema (vision + DOM)
  2. Navigator → finds Apply button (multi-strategy)
  3. WizardEngine → fills form (DOM + Vision + AI)
  4. OutcomeDetector → success/failure
  5. ReplayRecorder → saves workflow
  6. SitePatternStore → saves patterns (status=pending)
  
  If SUCCESS:
    → SitePatternStore.confirm_all_pending(domain)
    → LearningEngine.record_application(...)
    → Workflow is now "confirmed" — reusable

Second Visit to custom-company.com:
  1. SitePatternStore → load confirmed workflow
  2. ReplayRecorder → replay saved actions
  3. Only call AI for NEW questions (not in cache)
  4. OutcomeDetector → confirm
  5. 🎉 Much faster, no AI vision needed!
```

### 8.1 BlindApplier — Main Orchestrator

```python
class BlindApplier:
    """
    Главный класс для подачи на кастомных сайтах.
    
    Orchestrates:
    1. ReconAgent → Site analysis
    2. PageNavigator → Navigate to form
    3. VisionFormFiller → Fill form fields
    4. WizardEngine → Handle multi-step
    5. OutcomeDetector → Detect result
    6. ReplayRecorder → Record for learning
    7. SitePatternStore → Store patterns
    """
    
    async def apply(self, job: dict) -> ApplyResult:
        """
        Full blind apply flow.
        
        Args:
            job: Job dict with url/apply_url
            
        Returns:
            ApplyResult with success/failure
        """
        url = job.get("apply_url") or job.get("url", "")
        domain = urlparse(url).netloc
        
        # Шаг 0: Проверить кэш — есть ли confirmed workflow?
        cached_workflow = self.pattern_store.load_site_workflow(domain)
        if cached_workflow:
            logger.info(f"♻️ Replaying confirmed workflow for {domain}")
            return await self._replay_workflow(cached_workflow, job)
        
        # Шаг 1: Разведка
        async with StealthBrowser(headed=self.headed) as browser:
            async with await browser.new_context() as ctx:
                page = await browser.new_page(ctx)
                recorder = ReplayRecorder(job.get("id", ""), domain)
                
                # Navigate
                await page.goto(url, wait_until="domcontentloaded")
                recorder.record("navigate", url=url)
                
                # Recon
                schema = await self.recon.analyze(page)
                
                # Check if known ATS was detected
                if schema.detected_ats and schema.detected_ats != "unknown":
                    logger.info(f"🔄 Detected known ATS: {schema.detected_ats} — delegating")
                    return await self._delegate_to_known_ats(schema.detected_ats, job)
                
                # Check blockers
                if schema.blocked_reason:
                    return ApplyResult(success=False, error=schema.blocked_reason)
                
                if schema.requires_account:
                    return ApplyResult(success=False, error="account_required")
                
                # Navigate to form
                if schema.page_type == "job_listing" and schema.has_apply_button:
                    await self.navigator.click_apply(page, schema)
                    await asyncio.sleep(gaussian_delay(2.0, 4.0))
                    schema = await self.recon.analyze(page)  # Re-analyze
                
                # Fill form
                if schema.page_type in ("form_single", "form_wizard"):
                    result = await self.wizard.run_wizard(page, self.profile, recorder)
                    
                    # Detect outcome
                    outcome = await self.outcome_detector.detect(page)
                    
                    # Record for learning
                    recorder.save(success=outcome.success)
                    if outcome.success:
                        self.pattern_store.save_site_workflow(
                            domain=domain,
                            workflow=recorder._actions,
                            form_fingerprints=result.fingerprints,
                            success=True,
                        )
                    
                    return ApplyResult(
                        success=outcome.success,
                        filled=result.filled_fields,
                        error=outcome.error,
                    )
                
                return ApplyResult(success=False, error=f"unhandled_page_type:{schema.page_type}")
```

```python
async def _apply_blind(self, job: dict) -> str:
    """Apply via BlindApplier for custom/unknown sites."""
    logger.info(f"🔮 BlindApplier: trying {job.get('url')!r}")
    try:
        from src.applier.blind import BlindApplier
        
        applier = BlindApplier(headed=self.headed)
        result = await applier.apply(job)
        
        if result.success:
            if self.db:
                await self.db.update_status(job["id"], "applied")
            return ApplicationResult.SUCCESS
        elif result.error == "account_required":
            # Notify user — needs manual action
            if self.db:
                await self.db.update_status(job["id"], "external")
            return ApplicationResult.EXTERNAL
        else:
            if self.db:
                await self.db.update_status(job["id"], "error")
            return ApplicationResult.FORM_ERROR
    except Exception as e:
        return await self._handle_apply_error(job, e)
```

### 8.3 ATSDetector Extension

```python
# В ATSDetector: новый метод
def is_likely_custom_careers_page(self, url: str) -> bool:
    """
    Heuristic: URL, скорее всего, ведёт на кастомный карьерный сайт.
    
    Patterns:
    - careers.company.com
    - company.com/careers
    - company.com/jobs
    - company.com/join-us
    - company.com/opportunities
    """
    customs_patterns = [
        r"careers?\.",
        r"/careers",
        r"/jobs?(/|$)",
        r"/join-us",
        r"/opportunities",
        r"/apply",
        r"/openings",
        r"/vacancies",
    ]
    return any(re.search(p, url.lower()) for p in customs_patterns)
```

## 10. Risk Matrix & Mitigations

| # | Risk | Impact | Probability | Mitigation |
|---|------|--------|-------------|------------|
| R1 | CAPTCHA на кастомном сайте | 🔴 High | 🟡 Medium | Detect via vision → skip + notify user via Telegram |
| R2 | Требование аккаунта/SSO | 🔴 High | 🔴 High | ReconAgent detects → mark as "external" → send URL to Telegram |
| R3 | AI hallucination (нажать не ту кнопку) | 🟡 Medium | 🟡 Medium | Confidence threshold (>0.7), vision verification pass, human-in-the-loop для low confidence |
| R4 | Custom React/Vue компоненты непробиваемые | 🟡 Medium | 🟡 Medium | Vision coordinate click fallback, shadow DOM piercing JS |
| R5 | Rate limiting / IP ban | 🔴 High | 🟢 Low | `StealthBrowser` + `TimingEngine` уже реализованы |
| R6 | Двойная подача | 🟡 Medium | 🟢 Low | Domain+URL dedup в `SitePatternStore` + email confirmation check |
| R7 | Потеря данных (форма не отправлена) | 🟢 Low | 🟡 Medium | Screenshot before submit, ReplayRecorder saves actions |
| R8 | Kimi/Gemini API downtime | 🟡 Medium | 🟢 Low | Fallback chain: Kimi → Gemini → Claude → GLM-5 |
| R9 | Cost explosion (слишком много vision calls) | 🟡 Medium | 🟡 Medium | Budget limiter (max N vision calls per application), cache aggressively |
| R10 | Форма требует данные, которых нет в профиле | 🟢 Low | 🟡 Medium | AIAnswerer generates answers, HITL review for low-confidence |
